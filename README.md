# Dada

Dada is a service for video calls. This plugin adds one connector: the Dada MCP server at `https://mcp.da-da.pro`.

## Add it to Claude

1. Open **Customize > Plugins > Add > Add marketplace** and enter `RWizard/dada-ai-plugin`.
2. Add the **Dada** plugin.
3. Open the plugin's **Connectors** tab and select **Connect**.
4. Sign in to Dada in the window that opens and choose what the connector may do.

You can revoke the connection at any time on the Integrations page of your Dada account.

## Data

The connector talks to your Dada account through `mcp.da-da.pro`. The plugin itself stores nothing and contains no keys.

API documentation: https://docs.da-da.pro
